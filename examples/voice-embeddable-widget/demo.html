Grok embeddable voice widget

This page loads grok-voice-widget.js with one script tag. Start the companion token server first so the browser never sees your API key: 

set XAI_API_KEY=your_key
node session-token-server.mjs
# or: python session-token-server.py

Then open this file via a local static server (microphone requires a secure context — localhost is fine). Click the floating mic button → Start.
